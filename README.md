# Event Ticket System

A Java application demonstrating OOP principles, sorting/searching algorithms, and exception handling for managing event tickets.

## Features

1. **OOP Implementation**:
   - Base (Ticket) class with common properties
   - (VIPTicket) and (GeneralTicket) subclasses demonstrating inheritance
   - Polymorphism through method overriding
   - Encapsulation with private fields and public getters/setters

2. **Sorting & Searching**:
   - Selection Sort (by price)
   - Insertion Sort (by holder name)
   - Linear Search (by name)
   - Binary Search (by price)

3. **Exception Handling**:
   - Custom (NegativePriceException) for invalid ticket prices
